# Artinz

Premium independent fragrance house website.

**ONE HOUSE. FOUR HOURS.**

## Stack

- Next.js 15 (App Router)
- TypeScript
- CSS custom properties (`styles/artinz.css`)

## Development

```bash
npm install
npm run dev
```
